# Состав группы
Перов Станислав (github: conte-ananas), Фёдор Карпеев (github:fedosikpro2000)
# Идея проекта
В центре Москвы создаётся станция выдачи паспортов путешественника (каждая страница посвящена определенной достопримечательности Подмосковья). Посещая места из списка, участники акции получают печати в паспорт; за определённое количество печатей полагается приз. На станции будут также выдаваться буклеты с предлагаемыми маршрутами, в них будет содержаться рекламная информация (например, в какое кафе лучше зайти во время поездки). Это позволит получать дополнительный доход.
